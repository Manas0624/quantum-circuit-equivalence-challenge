# AI Usage Policy

AI assistance is allowed for this challenge.

Participants may use ChatGPT, Codex, Claude, Gemini, GitHub Copilot, autonomous coding agents, local models, and other AI-assisted development tools unless later published challenge rules specify otherwise.

Participants remain responsible for:

- submitted code
- correctness
- licenses
- dependency declarations
- security
- reproducibility
- compliance with challenge rules

Do not submit code or data that you do not have the right to use.
